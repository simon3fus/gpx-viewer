# GPX Viewer

Interaktiver GPX-Viewer zur Darstellung von GPS-Tracks (z.B. für Wanderungen, Bike- und Laufstrecken) mit Höhenprofil und Routenliste.

## Live Demo

**[Hier ansehen](https://simon3fus.github.io/gpx-viewer/)**

## Features

- Anzeige von GPX-Tracks auf interaktiver Karte (Leaflet)
- Höhenprofil mit Interaktion
- Routenliste mit Statistiken (Distanz, Höhenmeter etc.)
- Download einzelner Tracks
- Responsive Design (Mobile & Desktop)

## Technologie

- Pure HTML/CSS/JavaScript – keine Build-Tools nötig
- [Leaflet](https://leafletjs.com/) für die Kartenansicht
- OpenStreetMap als Kartenquelle

## Nutzung

Einfach `index.html` im Browser öffnen oder die Live-Demo besuchen.
